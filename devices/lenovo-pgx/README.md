# Lenovo ThinkStation PGX (hostname `lama`)

NVIDIA GB10 with 128 GB, on the workstation profile. Its kernel, NVIDIA driver and Ollama
come from the caches, so updates compile nothing here; `dgx-dashboard` and
`dgx-spark-mlnx-hotplug` are still unpacked locally by the DGX Spark module.

Hardware support lives under `lenovo-pgx/` in
[bresilla/devices](https://github.com/bresilla/devices).
